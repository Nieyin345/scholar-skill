# 综述写作规范

版本：v3.1（2026-08-04）
适用：流程一 · 步骤三 / 产出 `论文/<主题>/03_文献综述.md`
模板：`references/literature-review-template.md`
执行方式：本规范 + `通用写作规范.md` **同时生效**（反 AI 腔、过度声称护栏、术语保护、完整性底线见通用规范）。

## 1. 写作目标

- 让读者只看综述就能理解该方向：研究脉络、主流方法、共识与分歧、研究空白；
- **完全基于已下载文献（MD 文件）撰写**，综述是「文献的证据综合」，不是个人观点堆砌；
- 综述不是文献罗列，而是**主题化综合 + 批判性分析 + 空白推导**。

## 2. 结构要求

1. 摘要（含检索方法与范围）；
2. 引言：研究背景、范围边界、方法学自述（数据库、检索式、时间窗、纳入/排除标准、纳入文献数）；
3. 主题章节：**按主题/方法/结论组织，禁止按作者-年份逐条枚举**（如「张三（2019）提出……，李四（2020）发现……」）；
4. 跨主题综合：收敛结论、分歧与争论、方法学观察；
5. 研究空白与展望（必须由前述文献证据推导，不能凭空断言）；
6. 结论；
7. 参考文献列表。

### 2.1 主题章节的组织方式

每个主题簇内部按以下顺序展开：

1. **共识先行**：该主题下多数文献支持的结论（附代表文献）；
2. **分歧与争论**：冲突的结果、方法差异导致的结论差异（附双方证据）；
3. **批判性分析**：章节末尾给出小结——这些文献整体上解决了什么、局限在哪；
4. **与主题的关联**：一句话说明该主题与整个研究方向的关系。

研究空白章节必须满足：**每个空白点都要能指回前面的文献证据**（「现有方法在 X 场景下未见评估，见 §3.2」），不允许无依据的「尚需进一步研究」。

## 3. 语言与表达

- 结论先行：每段第一句给观点，后续给证据；
- 客观中性：区分「文献报道 X」与「我们认为 Y」；
- 证据强度与措辞匹配：`observed` 不写成 `strong`（确定性阶梯与替换表见 `通用写作规范.md` §2）；
- 区分「文献结论」与「综述者推断」：文献原文的结论用「文献报道 / 作者认为」，综述者自己的综合判断用「综上 / 我们认为」，二者不可混写；
- 避免空洞套话，每句话都有信息量；
- 写作全程过一遍反 AI 腔自检（通用规范 §1、§5）。

## 4. 引用与溯源（禁止编造）

- 每条观点必须可回溯：正文引用用 Obsidian wikilink 可点击跳转到论文 MD（禁止纯文本 `[序号]` / 作者-年份）；
- 只引用已下载且已转 MD 的文献；未获取全文的标注「未获取全文，未纳入综述」；
- **可跳转引用（硬性，Obsidian wikilink 标准）**：所有生成文档都放在 Obsidian vault，正文引用与参考文献条目一律用 Obsidian wikilink `[[…]]` 链接到对应论文 MD，纯文本编号不合格：
  - **编号样式**：正文引用显示为编号 `[1]`、`[2]`…（**不是作者名**），按正文首次出现顺序全局编号，同一文献用同一编号；参考文献列表按编号升序排列；
  - **文末参考文献小节（必写）**：正文结束后加 `## 参考文献`，按编号升序列出（`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号] <完整参考文献>]]`），编号与正文一一对应；
  - 正文引用：`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号]]]`（**路径限定，最稳**；如 `[[论文/QKD调度/2024-smith-xxx/2024-smith-xxx|[1]]]`）；
  - 参考文献条目：`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号] <完整参考文献>]]`；
  - md 文件名在 vault 内唯一时可简写：`[[<md文件名>|[编号]]]`；
  - 文档互引（`01_检索结果` / `02_检索日志` / 导航等）同样用 `[[文件名]]`；
  - **链接目标必须是 md 文件，禁止把论文文件夹名当链接目标**；链接前用 `rg --files 论文/<主题> -g "*.md"` 核对真实文件名（历史遗留文件以实际文件名为准）；
  - 转换稿 md 顶部自带「原文 PDF」链接（`[[<论文短名-年>.pdf]]`，转换脚本自动插入），需要时可再链；
  - 相对 Markdown 链接（`[文本](./路径/文件.md)`）仅用于导出到 Obsidian 外（如 GitHub 预览）时替代；
  - 参考文献列表每条同样用 wikilink；未下载 / 未转换文献不得出现在正文引用与参考文献（只能以「未获取全文」说明列出）；
- 引用核验：初稿后用 `scripts/citation-verification/verify-citations.py` 核对 DOI/标题/作者/年份；
- 禁止编造文献、数据、指标、他人观点；
- 同一句话内堆叠引用不超过 2 个；连续引用超过 2 个时必须逐个说明各自贡献（避免「引用堆砌」）。

## 5. 检查清单

- [ ] 每条观点都有来源标注
- [ ] 每条引用均为可点击编号引用（Obsidian wikilink 显示 `[1]/[2]…`，编号连续无跳号），指向真实存在的论文 MD（逐条核对 `[[…]]` 目标是 `.md` 文件，不是文件夹名）
- [ ] 未获取全文的文献已明确标注
- [ ] 矛盾证据已被覆盖（无 cherry-picking）
- [ ] 包含一段方法学自述（可复现）
- [ ] 参考文献与正文一一对应
- [ ] 已跑引用核验，无失败项
- [ ] 主题章节按主题组织，无「作者-年份」逐条枚举
- [ ] 每个主题簇末尾有批判性小结
- [ ] 研究空白均由前述证据推导并指回来源
- [ ] 通过通用规范反 AI 腔与过度声称自检
