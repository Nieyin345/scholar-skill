# 论文写作规范

版本：v2.5（2026-08-07）
适用：流程四 / 产出：`论文/<主题>/thesis/` 内 `main.tex` + 编译 `main.pdf`（可含中文定稿 `draft-zh.md`）
模板：`论文/<主题>/thesis/template/`（原始模板参考，只读）+ `thesis/` 根（工作副本）
执行方式：本规范 + `通用写作规范.md` **同时生效**（反 AI 腔、过度声称护栏、术语保护、完整性底线见通用规范）。

> 定位：本规范只回答三件事——**①结构以模板为准；②不编造；③不 AI 味**。v2.5 起删除了此前的「摘要五要素 / 引言漏斗 / 结果证据阶梯 / 结论四段式」等细碎写作框架：**模板本身就是一篇论文，照模板的结构写即可**，外部写作框架只会制造 AI 味。

## 1. 核心原则

1. **结构以模板为准（铁律）**：打开 `thesis/template/` 主 tex，**模板是什么结构就怎么写**——章节顺序、小节层级、段落粒度、格式全部照模板；模板没有的章节不发明（除非用户要求），模板有的不省略；
2. **不编造（铁律）**：数字 / 图表 / 引用 / 结论只能来自流程二/三与已读文献（先读后写）；禁止用模型既有知识填充具体发现 / 数字 / 对比结果；
3. **不 AI 味（铁律）**：
   - **禁止碎点化**：小节必须有实质内容，一个章节通常 3-5 个小节以内，不把内容拆成一堆空泛小点；
   - **自然连贯**：像学者写论文，不清单化；避免「首先 / 此外 / 值得注意的是」堆砌、空泛套话、机械三句式、每段套路的过渡词。

## 2. 写作形式（两阶段，固定）

**阶段A：中文 MD 内容定稿（先不翻译）**

1. **读模板结构**：完整读取 `thesis/template/` 主 tex 的章节 / 小节结构与格式，转成写作大纲；
2. **写中文稿（Writer）**：严格按模板结构写中文稿（md，引用用 Obsidian wikilink）；内容完整、写实写透；
3. **润色中文（Polisher）**：语言打磨、术语统一、反 AI 味，**不改内容与结论**；
4. **内容 Review**：对照模板检查结构符合 / 内容完整准确 / 自然连贯 / 引用图表，循环至通过 → **中文稿定稿**；**未定稿前禁止翻译**。

**阶段B：翻译为英文 LaTeX + 翻译质量迭代**

5. **翻译（Translator）**：中文定稿 → 英文，**直接编辑工作副本 `thesis/main.tex`**（保留模板封面 / 背景 / 章节宏）；翻译意图不翻译句式；忠实不增删、结论强度不变；
6. **英文润色（Polisher）**：语法正确、自然流畅、不 AI 味；
7. **翻译 Review**：只审翻译质量（忠实度 / 术语 / 英文质量 / LaTeX 正确性），循环至通过；
8. **编译**：`python scripts/latex/compile_latex.py thesis/main.tex` → `thesis/main.pdf`，编译通过为底线。

## 3. 模板要求（只读参考 + 工作副本）

- `thesis/template/` = **原始模板参考**，**只读、禁止修改**；`thesis/` 根 = **工作副本**（写作 / 编译处）；
- 模板资源（`.cls/.sty/图片/封面/背景`）**禁止删除、替换、瘦身**——封面 / 背景 / 版式依赖它们渲染；
- 主文件以模板实际为准（一般 `main.tex`）；编译在工作副本内进行，输出 `thesis/main.pdf`；
- **对照模板检查**：review 与交付前都打开 `thesis/template/` 核对封面页、章节结构、双栏/单栏、字体字号、引用格式、图注/表注。

## 4. 引用与核验规范（禁止编造）

- **绝不用记忆生成 BibTeX**（AI 生成引用错误率极高，编造参考文献 = 学术不端）；
- 引用必须程序化验证（CrossRef / arXiv / Semantic Scholar / 检索核验）或来自流程一核验过的文献库；
- 无法确认的引用：写 `\cite{PLACEHOLDER_author_year_verify}` 并明确告知用户「有 N 条待人工核对」，不猜测补全；
- md 稿文末 `## 参考文献` 按编号升序列出（wikilink 可点击跳转）；转 LaTeX 时 `\cite{key}` + `references.bib` 逐条一一对应（无幽灵引用、无漏引）；映射表写入 changelog；
- 引用准确反映原文内容（配合 `citation-verification`）。

## 5. Review 规范

**内容 Review（阶段A，对照模板）：**

1. **结构符合（最重要）**：章节 / 小节与 `thesis/template/` 一致——模板有的都有、模板没有的没发明、顺序正确、粒度一致；
2. **内容完整准确**：每个章节写实，主张有证据（`[CLAIM NEEDS EVIDENCE]` 清零），数字 / 图表与素材一致；
3. **自然连贯（防 AI 味）**：无碎点化、无空洞小点、无套话、无机械过渡；
4. **引用与图表**：引用完整可跳转、图表有来源、图注表注符合模板。

- 总判定：通过 / 需中修 / 中断；**研究层面问题 → 中断**（缺实验 / 对比 / 数据 → 返回流程二/三），写作层面问题 → 下一轮内容循环；
- 评审协议：独立 → 交叉 → 合成，用户最终确认。

**翻译 Review（阶段B，只审翻译质量）：**

- 忠实度：与中文定稿逐段对应，无漏译 / 误译 / 增删；数字、符号、结论强度一致；
- 术语一致性：术语表（02/03）统一，未擅自替换冻结术语（通用写作规范 §3.1）；
- 英文质量：语法正确、自然流畅、不 AI 味；
- LaTeX 正确性：`\cite` / `\ref` / `\eqref` 齐全无悬空；对照 `thesis/template/` 检查格式符合度；
- 总判定：通过 / 需再润色；发现内容 / 研究问题（阶段A漏检）返回阶段A处理，不在英文稿上直接改内容。

## 6. 迭代与存档规范

1. 每轮 review 后把当轮定稿与 `review-vN.md`、`changelog-vN.md` 存入 `thesis/versions/vN/`，版本号连续递增、**只增不删**；
2. `changelog-vN.md` 逐条对应 review 问题：`问题 → 修改 → 复核 → 证据`；未逐条解决并复核前不得声称完成（负面判据）；
3. 轮次定义：内容轮 = 「写中文 → 润色 → 内容 Review」（阶段A）；翻译轮 = 「翻译/润色英文 → 翻译 Review」（阶段B）；
4. **下一轮只修 review 指出的问题**，不夹带新内容；不清楚的意见先澄清；对错误意见用技术理由反驳；连续两轮未解决回根因。

## 7. 完整性底线

1. 不编造文献、数据、指标、他人观点；
2. 数字必须与流程三 `results/` 一致；图表必须来自 `figures/`、`tables/`；
3. 结论强度不超过证据（通用规范 §2 过度声称护栏）；
4. 负面结果、局限、缺失基线诚实呈现，不粉饰。

## 8. 检查清单（交付前）

- [ ] 结构严格遵循 `thesis/template/`（模板有的章节都有、没发明的、顺序正确）
- [ ] 无碎点化：小节有实质内容，章节未拆成大量小点
- [ ] 语言自然连贯，无套话 / 机械过渡 / AI 味
- [ ] 数字 / 图表 / 引用来自流程二/三与已读文献，无编造
- [ ] 引用 wikilink 可点击跳转 ↔ `\cite` 一一对应；`.bib` 程序化验证或标注 PLACEHOLDER 并已告知用户
- [ ] 内容 Review 通过（对照模板：结构 / 完整 / 连贯 / 引用）+ 翻译 Review 通过（忠实度 / 术语 / 英文 / LaTeX）
- [ ] 编译通过（无 Error、无悬空引用、PDF 产出）；`thesis/template/` 未修改、模板资源完整
- [ ] `thesis/versions/` 存档完整：每轮定稿 + review 报告 + changelog
