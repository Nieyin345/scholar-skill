# 综述写作规范

版本：v2.0（2026-08-03）
适用：流程一 · 步骤三 / 产出 `<主题>/文献综述.md`
模板：`references/literature-review-template.md`
执行方式：本规范 + `通用写作规范.md` **同时生效**（反 AI 腔、过度声称护栏、术语保护、完整性底线见通用规范）。

## 1. 写作目标

- 让读者只看综述就能理解该方向：研究脉络、主流方法、共识与分歧、研究空白；
- **完全基于已下载文献（MD 文件）撰写**，综述是「文献的证据综合」，不是个人观点堆砌；
- 综述不是文献罗列，而是**主题化综合 + 批判性分析 + 空白推导**。

## 2. 结构要求

1. 摘要（含检索方法与范围）；
2. 引言：研究背景、范围边界、方法学自述（数据库、检索式、时间窗、纳入/排除标准、纳入文献数）；
3. 主题章节：**按主题/方法/结论组织，禁止按作者-年份逐条枚举**（如「张三（2019）提出……，李四（2020）发现……」）；
4. 跨主题综合：收敛结论、分歧与争论、方法学观察；
5. 研究空白与展望（必须由前述文献证据推导，不能凭空断言）；
6. 结论；
7. 参考文献列表。

### 2.1 主题章节的组织方式

每个主题簇内部按以下顺序展开：

1. **共识先行**：该主题下多数文献支持的结论（附代表文献）；
2. **分歧与争论**：冲突的结果、方法差异导致的结论差异（附双方证据）；
3. **批判性分析**：章节末尾给出小结——这些文献整体上解决了什么、局限在哪；
4. **与主题的关联**：一句话说明该主题与整个研究方向的关系。

研究空白章节必须满足：**每个空白点都要能指回前面的文献证据**（「现有方法在 X 场景下未见评估，见 §3.2」），不允许无依据的「尚需进一步研究」。

## 3. 语言与表达

- 结论先行：每段第一句给观点，后续给证据；
- 客观中性：区分「文献报道 X」与「我们认为 Y」；
- 证据强度与措辞匹配：`observed` 不写成 `strong`（确定性阶梯与替换表见 `通用写作规范.md` §2）；
- 区分「文献结论」与「综述者推断」：文献原文的结论用「文献报道 / 作者认为」，综述者自己的综合判断用「综上 / 我们认为」，二者不可混写；
- 避免空洞套话，每句话都有信息量；
- 写作全程过一遍反 AI 腔自检（通用规范 §1、§5）。

## 4. 引用与溯源（禁止编造）

- 每条观点必须可回溯：`[序号]` 对应 `01_检索结果.md`，或作者-年份；
- 只引用已下载且已转 MD 的文献；未获取全文的标注「未获取全文，未纳入综述」；
- 引用核验：初稿后用 `scripts/citation-verification/verify-citations.py` 核对 DOI/标题/作者/年份；
- 禁止编造文献、数据、指标、他人观点；
- 同一句话内堆叠引用不超过 2 个；连续引用超过 2 个时必须逐个说明各自贡献（避免「引用堆砌」）。

## 5. 检查清单

- [ ] 每条观点都有来源标注
- [ ] 未获取全文的文献已明确标注
- [ ] 矛盾证据已被覆盖（无 cherry-picking）
- [ ] 包含一段方法学自述（可复现）
- [ ] 参考文献与正文一一对应
- [ ] 已跑引用核验，无失败项
- [ ] 主题章节按主题组织，无「作者-年份」逐条枚举
- [ ] 每个主题簇末尾有批判性小结
- [ ] 研究空白均由前述证据推导并指回来源
- [ ] 通过通用规范反 AI 腔与过度声称自检
