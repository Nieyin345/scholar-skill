## 1. 写作目标

- 把模糊方向收敛为**一句话能说清、SMART、可证伪**的研究问题 + 明确范围；
- 每个判断（空白、新颖性、取舍、方法）都有文献证据（Evidence Record）或用户确认支撑；
- 产出物通过 Proposal Readiness Gate，能直接作为流程一的检索输入。

## 2. 结构要求（00_研究方向.md）

1. **研究方向卡**：一句话研究问题（SMART）、问题类型（exploratory/confirmatory/applied）、主方向与备选、范围（in/out）、目标与预期贡献；
2. **研究空白与依据**：五类 gap（文献/方法/应用/交叉/时间）+ 证据记录引用；禁止「未见相关工作」这种无法证伪的表述；
3. **新颖性与差异化**：novel/not-novel 判定、最相似论文 3–5 篇、与每篇的差异说明；
4. **初步方法路线**：问题类型 → 方法类别（理论/实证/系统/数据）→ 关键技术 → 数据/算力需求 → 主要风险；
5. **约束与资源 + 时间线**：数据 / 算力 / 时限 / 协作；准备→探索→开发→完成 4 阶段 + 里程碑；
6. **种子文献清单**：综述 + 高引文献（标题/年份/引用数/venue/DOI，标注来源质量等级）；
7. **最小下一步 + 决策日志**：进入流程一后先做什么；date/decision/why 记录。

## 3. 结构要求（00_研究问题卡.md，可选独立文件）

```
## Research Question Card
Question:
Type: exploratory | confirmatory | applied
Hypothesis:（H₁，尽量有方向；附 H₀）
Why it matters:
Current evidence:（引用 Evidence Record ID）
Missing evidence:
What would support it:
What would falsify it:（证伪标准，具体数据模式）
Minimal next action:
Decision: explore | read more | run experiment | stop
```

## 4. 证据记录规范（Evidence Record）

- 每条关键判断（空白、新颖性、方法可行性）配一条证据记录；
- ID 格式：`ER-YYYYMMDD-slug-NN`（如 `ER-20260803-medimg-seg-01`），禁止 `E1`、`paper1` 这类含糊 ID；
- 字段：Source / Source type（full paper | preprint | dataset | experiment artifact | project note | abstract-only | webpage placeholder）/ Supports / Contradicts / Method-dataset-metric / Limitation / Project relevance / Claim strength；
- **证据强度分级**：`speculative`（弱证据）/ `observed`（见过但不足以成结论）/ `supported`（有明确证据）/ `strong`（多证据锚点或严格统计）；**升级强度必须点名证据**；
- abstract-only / 网页占位只能用于发现与 To-Read，不能支撑方向判断（Claim Promotion Gate）。

## 5. 语言与表达

- 结论先行：研究问题放最前，一句话说清（说不清 = 流程0未完成）；
- 评分（有趣性/新颖性/可行性 1–10）必须附理由，不写裸分数；
- 假设、方法可行性等未验证内容标注「待验证」，不用确定性语气；
- 不编造数据/文献支撑假设；相关关系不写成因果关系。

## 6. 检查清单（交付前）

- [ ] 研究问题一句话说清且满足 SMART（说不清则不进入流程一）
- [ ] 问题类型明确（探索/验证/应用）
- [ ] H₀/H₁、变量矩阵、证伪标准齐全
- [ ] 范围 in/out 明确
- [ ] 每个候选子方向有文献快照 + 来源质量分级
- [ ] gap/novelty 判断有证据记录引用（≥3 轮检索，附最相似论文）
- [ ] 方法路线由问题驱动，资源约束现实
- [ ] 三维评分与取舍有理由，决策日志完整
- [ ] 种子文献真实可查（含 DOI），无编造
- [ ] 通过 Proposal Readiness Gate（问题卡/证据/缺失证据/下一步/文献五项）
- [ ] 最小下一步明确（进入流程一）
- [ ] 通过通用规范反 AI 腔与过度声称自检
