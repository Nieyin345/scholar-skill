# 工具：书籍库管理（教材 PDF 归类与转换）

> 独立小工具：管理 scholar 的**书籍库**（PDF 教材库）——只做**骨架创建 + 增量维护**。
> **职责边界**：**只处理书籍/教材**（第一级总教材库 → 第二级方向 → 第三级教材文件夹 → pdf/md/图床）；**不管理论文库与学习笔记库**——论文库由主流程 + 项目导航文档（`<主题>/00_项目导航.md`）管理，学习笔记库由「学习笔记」工具（`tools/学习笔记.md`）管理。
> 定位：**不随主 SKILL.md 触发路由自动执行**（避免每次触发就检查文件系统）；由用户按需触发（触发词见下），或在流程/工具结束时按需调用。

---

## 触发条件

- 用户要求：导入教材 / 书籍入库 / 整理教材 / 检查新 pdf / 分类教材 / 教材转 md / books / textbook；
- 或用户手动往书籍库放入新 PDF 后要求「帮我归类转换」；
- 注意：**不是**每次触发 scholar 都自动跑本工具——由用户显式触发。

## 书籍库三级结构

```
Books/                        ← 第一级：总教材库
├── 00_索引.md                ← 书籍库导航（本工具维护，文件变动时更新，只增不删）
├── 通信/                     ← 第二级：方向（通信 / 机器学习 / 数学 / …）
│   └── 通信原理/             ← 第三级：教材文件夹（教材名字）
│       ├── 通信原理.pdf
│       ├── 通信原理.md        ← MinerU 转换产物
│       └── (图床/)           ← 图片资产目录，由转换脚本自动生成，不用管
└── 机器学习/
    └── 深度学习/（.pdf .md 图床）
```

- 默认位置：`<books-root>`（默认 `~/OB_database/Books`，可配置，如 `--root`；首次触发时向用户确认实际位置，之后记住不再问）；
- 教材的**导入由用户操作**（把 PDF 放入 Books 根目录或某方向目录）；
- 本工具负责：发现游离 PDF → 与用户确认归类（方向+教材名）→ 建第三级文件夹 → 移动 PDF → 转 MD → 更新 `00_索引.md`。

## 触发时动作（只建骨架，不扫描）

1. 确认书籍库根目录存在（不存在则创建，并提示用户导入教材）；
2. 创建 `00_索引.md`（不存在时；即书籍库导航文件）；
3. **结束**——不检查文件内容、不扫描论文库/学习笔记库。

## 维护动作（增量检查，按需触发）

1. **发现游离 PDF**：只检查 `Books/` 根目录与各方向目录下**不在第三级教材文件夹内**的 `.pdf`（不递归全盘、不检查其他库）；
2. **归类（用户确认）**：对每个游离 PDF，给出建议方向（按文件名/内容判断），与用户确认「方向 + 教材名」；新建 `<方向>/<教材名>/` 第三级文件夹并移动 PDF；
3. **转换**：调用 `scripts/convert_pdf_to_md.py <pdf> --out <教材文件夹>`（flash 免认证 / extract 精提取），产出 `<教材名>.md`；图床目录由脚本自动生成，不手动整理；
4. **登记索引**：在 `00_索引.md` 追加一行（教材名 / 方向 / PDF / MD / 转换日期 / 状态）；转换失败在状态列标注原因；
5. 重复 1-4 直到无游离 PDF。

## 配套脚本

`scripts/books_ingest.py`（用法见脚本 `--help`）：

| 命令 | 作用 |
|------|------|
| `python scripts/books_ingest.py ensure-skeleton --root <Books>` | 创建书籍库骨架 + `00_索引.md`（触发时动作） |
| `python scripts/books_ingest.py list-orphan-pdfs --root <Books>` | 列出游离 PDF（维护步骤 1） |
| `python scripts/books_ingest.py ingest --pdf <path> --category <方向> --title <教材名> [--mode flash|extract] --root <Books>` | 归类 + 移动 + 转换 + 登记索引（维护步骤 2-4） |

## 与学习笔记的衔接（可选）

- 教材也可生成学习笔记（概念/公式/方法）——复用「学习笔记」工具，笔记放 vault（如 `Books/` 目录）；
- 教材 `<教材名>.md` 是转换稿（源），笔记是提炼；不在书籍库复制笔记。

## 关键纪律

- **只处理书籍库**：不管理论文库与学习笔记库（各自有对应流程/工具管理）；不随总 skill 每次触发自动执行；
- **不做全盘扫描**：只检查「游离 PDF」这一种状态；
- **不擅自移动/删除用户文件**：归类与教材名先与用户确认；转换失败不静默，原因记入 `00_索引.md`；
- **教材导入由用户操作**：本工具只做「发现 → 归类 → 转换 → 登记」；
- **图床目录**由转换脚本生成与管理，不手动整理；
- **`00_索引.md` 是书籍库导航文件**：只在文件变动时更新（新增/删除/重命名/移动/转换完成），无文件变动的轮次不重写；与研究方向导航（`<主题>/00_项目导航.md`）、笔记库导航（`<项目短名>/00-导航.md`）同属「三库导航」体系，但本工具只维护书籍库这一个。
