# 通用写作规范（跨任务）

版本：v1.6（2026-08-06）
适用：scholar 所有写作任务（综述、解决方案三文档，以及后续新增流程的写作任务）
执行方式：各任务专属规范（如 `综述写作规范.md`）+ 本通用规范 **同时生效**；本规范回答「怎么写得好」，专属规范回答「这篇要写什么」。

## 1. 反 AI 腔（写作表达底线）

目标：像「有判断力的学者在写作」，不像「生成文本的机器」。**去 AI 味 ≠ 去学术性**，学术语体保留，只消除机械痕迹。

### 1.1 删除填充语

删掉清嗓子和强调拐杖，直接陈述：

| 避免 | 改为 |
|------|------|
| 值得注意的是 / 需要指出的是 | 直接陈述要点（或删除） |
| 为了实现这一目标 / 为了达成上述目标 | 直接说做法 |
| 基于……的事实 / 鉴于……这一事实 | 因为 / 由于 |
| 不言而喻 / 显而易见 | 删除或给出证据 |
| It is important to note that | (删除) |
| In order to achieve this goal | To achieve this |

### 1.2 机械过渡词

每段开头不要堆叠 `此外 / 另外 / 同时 / 综上所述 / Moreover / Furthermore / Additionally / In addition`。用「内容驱动的过渡」：引用上一段的结论词、具体名词、推进论证的短语，或让逻辑自然衔接。

### 1.3 抽象占位语

禁止用空洞短语占位，必须写出具体内容：

| 空洞 | 修复 |
|------|------|
| 多个因素 / 各种方面 | 逐一列出具体因素并量化 |
| 起到重要作用 / plays an important role | 说清「如何」作用（机制、方向、幅度） |
| 对……具有重要意义 | 具体说明意义落在哪里 |
| 相关研究表明 | 点名具体文献与具体发现 |
| 不同视角 / 不同方法 | 命名具体视角 / 方法 |

### 1.4 句式节奏

- 混合短句（强调关键结论）、中句（标准论述）、长句（复杂逻辑），避免每句 15-20 词等长；
- 连续三句长度接近时，拆改其中一句；
- 避免强行三段式（rule of three）与「不仅仅是 X，而是 Y」的否定平行结构；
- 破折号克制使用，不用来制造「机灵」效果。

### 1.5 常见 AI 高频词（中英文）

警惕：`至关重要 / 关键作用 / 深入探讨 / 增强 / 格局 / 此外 / 毋庸置疑`；`crucial / delve / enhance / landscape / testament / vital`。出现时检查是否换成更具体、更朴素的表达（如 `至关重要` → 说清具体影响与数据）。

### 1.6 避免空洞观点，保留学术克制

- 陈述事实后要有判断或点评，但判断必须有证据支撑；
- 承认不确定性与分歧（「该机制仍有争议」「证据尚不充分」是加分项，不是减分项）；
- 第一人称 `我们 / we` 仅在合适的文档类型中使用，不强加；
- 不写宣传腔（如「迈出重大一步」「划时代」）。

## 2. 过度声称护栏（证据强度 ↔ 措辞）

原则：**强证据配强措辞，弱证据配弱措辞**。目标是校准，不是把语气变怂。

### 2.1 确定性阶梯（动词，强 → 弱）

```
demonstrate / prove         ← 干预 + 受控实验（消融、随机对照、A/B）
reveal / identify / find    ← 强效应，多方法或已复现
indicate / suggest          ← 显著但单一方法
support / be consistent with ← 趋势、与既有工作一致
may indicate / could suggest ← 边缘或预测性结果
hint at / point toward      ← 很弱的信号或假设
```

写作时先问：我的证据能到哪一级？措辞不得超过证据一级。

### 2.2 替换表

| 场景 | ❌ 过度声称 | ✅ 保守表达 |
|------|-----------|-----------|
| 因果（最常见的过度声称） | 由……导致 / 决定了 / 证明了 | 与……相关 / 与……一致 / 提供了证据表明 |
| 首创性 | 首次 / the first to | 据我们所知，属于首批 / 我们首次（在明确的限定范围内） |
| 普适性 | 总是 / 从不 / 适用于所有情况 | 在所研究的场景中 / 在所评估的数据集上 |
| 效应量 | 显著提升 / 大幅改善（无数值） | 误差降低 X% / 指标从 X 提升到 Y（附统计量） |
| 影响/应用 | 将彻底改变 / 解决了……问题 | 为……提供了基础 / 为……提供了一种候选方案 |
| 贬低前人 | 先前方法都无法 / 全面超越所有工作 | 先前方法受限于…… / 与具体方法相比表现更好 |

**铁律**：有数字就删形容词；没有受控实验不得写因果；`first / novel / unprecedented / best / superior` 类词必须自带限定与证据。

### 2.3 高发陷阱短语

| 陷阱 | 安全改写 |
|------|----------|
| 我们的结果证明 X（X 是相关关系） | 我们的结果与 X 一致 |
| 这是第一个……的工作 | 据我们所知，这是首批……之一 |
| X 在 Y 中起关键作用 | X 与 Y 相关 / 可能对 Y 有贡献 |
| 这些发现具有重要意义 | 这些发现为进一步研究……提供了基础 |
| 强烈支持 | 与……一致 / 提供了与……相符的证据 |

### 2.4 反向校准（不要误伤）

以下情况允许强措辞，不要为改而改：

- 有受控干预（消融 / RCT / A-B 实验）→ `demonstrate` 成立；
- 多方法 / 多数据集 / 多次复现 → `robustly`（并点名证据）；
- 已复现的成熟机制 → `confirms / validates`；
- 大效应且有强统计量 → 强措辞 + 数字。

### 2.5 绝对词警戒清单

出现以下词时必须重新审视：`prove / conclusively / unprecedented / best / superior / first / 首次 / 证明 / 彻底 / 完全`。能换成 `show / suggest / to our knowledge / among the strongest / in this cohort / 据我们所知 / 表明 / 支持` 则换。

## 3. 术语与格式保护

### 3.1 领域术语冻结

以下术语有精确技术含义，**不得随意换同义词**：`gradient descent`、`backpropagation`、`attention mechanism`、`transformer`、`overfitting`、`fine-tuning`、`embedding`、`precision / recall / F1`、`BLEU / ROUGE`、`convex / concave`、`stochastic`、`null hypothesis / p-value`、`ablation study`、`baseline`、`benchmark`、`corpus`。需要修改必须经用户确认。

### 3.2 引用与数学内容保护

- 文献引用键（`\cite{key}`、`[1]`、`(Author, 2020)`）不得改动，否则引用断裂；
- 交叉引用（`\ref`、`\label`）、公式环境（`$...$`、`equation`、`align` 等）内部内容不改动；
- 数学符号、索引、算子修改可能无声改变数学含义，非必要不动。

### 3.3 数字、单位与标点

- 测量值用数字，数值与单位间留空格：`25 cm`、`3.2 s`；
- 统计符号、数学记号全篇一致；
- 中文文本用全角标点，英文文本与公式内用半角标点（适用于中文学位论文场景）；
- 缩写首次出现给出全称；
- 表格内同一列数字精度一致；显著性标记需在表注中定义。

### 3.4 学术语体

- 慎用口语化表达、修辞问句、`we` 的滥用；
- 一个句子表达一个主要命题；独立分句之间不用逗号连接；
- 每段有一个控制性观点 + 支撑材料；
- 避免 `although / whereas` 引导的残缺句。

### 3.5 数学公式规范（LaTeX + Obsidian 兼容）

**铁律：所有 md 文档中的数学公式一律用 LaTeX 语法书写，且必须是 Obsidian 原生可渲染的写法。** 禁止用公式截图 / 图片、Unicode 伪公式（`x²`、`y₁`、`√(a²+b²)`）或纯文字描述代替公式。

- **定界符（Obsidian 原生）**：行内公式用 `$...$`（如 `损失为 $L = -\sum_i y_i \log \hat{y}_i$`）；块级公式用独占一行的 `$$...$$`；统一不用 `\(...\)` / `\[...\]` / `\begin{equation}` 等其它定界符（留给流程四 `.tex` 阶段）；
- **LaTeX 语法**：函数 / 算子必须加反斜杠（`\sin`、`\log`、`\max`、`\sum`、`\int`），裸写 `sin` / `log` 会被当作变量乘积；向量 / 矩阵 / 集合用 `\mathbf` / `\mathcal` / `\mathbb`，与 02/03 文档符号约定一致（§3.1 术语冻结）；公式内中文用 `\text{}` 包裹；多行推导用 `$$` + `\begin{aligned}...\end{aligned}`（Obsidian 原生支持）；
- **公式编号**：md 阶段不强制编号；需要指向时在公式末尾加 `\tag{N}`，正文写「式 (N)」对应；
- **与流程四 `.tex` 的衔接**：md 稿（中文 / 英文）阶段一律 `$` / `$$`（Obsidian 渲染）；转 `paper.tex` 时逐条映射——行内 `$...$` → `\(...\)`，块级 `$$...$$` → `\[...\]`（或 `equation` 环境），`\tag{N}` → `\label{eq:N}`，正文「式 (N)」→ `\ref{eq:N}`；公式内容（LaTeX 命令）在 md 与 .tex 之间保持一致，不重写数学；
- **代码中的公式（流程三）**：注释 / docstring 中的数学公式同样用 LaTeX 记法（行内 `$...$`），与文档符号一致，不写伪 Unicode。

## 4. 引用与链接（全局强制 · Obsidian wikilink 标准）

**适用范围（全局，不止综述）**：所有流程产出的所有 md 文档——流程0（`00_研究方向.md` / `00_研究问题卡.md` / `00_文献验证.md`）、流程一（`01_检索结果.md` / `02_检索日志.md` / `03_文献综述.md`）、流程二（解决方案三文档）、流程四中文稿/英文稿（md 阶段）、学习笔记、书籍库文档、导航文档。**只要文档里出现文献引用，就必须可点击跳转到对应论文 MD**；文档互引同样用 wikilink。相对 Markdown 链接仅在用户明确要求导出到 Obsidian 外（如 GitHub）时作为替代。

- **库内引用必须可点击跳转到对应论文 MD**，禁止只写纯文本编号 / 作者-年份；**链接目标必须是 md 文件本身，禁止把论文文件夹名当链接目标**（Obsidian 无法跳转文件夹）；
- **编号规则（学术引用样式）**：正文引用一律显示为编号 `[1]`、`[2]`…（**不是作者名 / 作者-年份**），编号按正文**首次出现顺序**全局分配；同一文献重复引用用同一编号；参考文献列表按编号升序排列；
- **文末参考文献小节（全局强制）**：任何含引用的 md 文档（综述 / 方案文档 / 代码架构 / 中文稿英文稿 / 方向文档等），正文结束后必须加 `## 参考文献`，按编号升序列出全部被引文献（`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号] <完整参考文献>]]`）；编号与正文一一对应：正文引用过的必须出现、列表里的必须被正文引用过（无幽灵引用 / 漏引）；**没有引用的文档不需要该小节**；
- 标准语法：
  - 正文引用：`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号]]]`（**路径限定，最稳**；如 `[[论文/QKD调度/2024-smith-xxx/2024-smith-xxx|[1]]]`）
  - 参考文献条目：`[[论文/<主题>/<论文短名-年>/<md文件名>|[编号] <完整参考文献>]]`
  - md 文件名在 vault 内唯一时可简写：`[[<md文件名>|[编号]]]`（如 `[[2024-smith-xxx|[1]]]`）
  - 文档互引（导航 / 检索结果 / 综述 / 笔记之间）：`[[<文件名>|<显示文本>]]`，如 `[[01_检索结果]]`、`[[00_项目导航]]`
- **链接前必须核对文件系统**：用 `rg --files 论文/<主题> -g "*.md"`（或直接看目标文件夹）确认真实 md 文件名再写链接；**禁止凭文件夹名 / 记忆推断**；历史遗留转换稿（`full.md`、原标题名等）以实际文件名为准；
- wikilink 用**去扩展名的真实 md 文件名**：新转换产物统一为 `<短名>.md`（转换时传 `--md-name <短名>`，产物与论文文件夹同名）；
- **每个转换出的论文 md 顶部自带「原文 PDF」链接**（`[[<论文短名-年>.pdf]]`，由 `scripts/convert_pdf_to_md.py` 自动插入）；正文 / 笔记中需要跳 PDF 时直接再链 `[[<论文短名-年>.pdf|PDF]]`；
- 未下载 / 未转换的文献不得进入正文引用与参考文献；正文引用的每条必须同时出现在参考文献列表，且列表条目同样用 wikilink；
- 相对链接 `[文本](./路径/文件.md)` 仅用于导出到 Obsidian 外的场景，Obsidian 内一律 wikilink。
- **`.tex` 例外**：流程四 LaTeX 定稿（`paper.tex`）用 `\cite{key}` + `references.bib`（编译产物，不适用 wikilink）；md 稿（中文/英文）阶段一律 wikilink，转 LaTeX 时逐条映射为 `\cite`，保持引用一一对应。
- 文档内流程图 / 架构图 / 训练管线用 **Mermaid 内嵌 md**（Obsidian 原生渲染），不放进外部图片文件；出版级矢量导出见 `tools/科研插图.md`。

## 5. 引用与完整性底线

1. **禁止编造**：不编造文献、引用、数据、指标、他人观点；
2. **不升级因果**：相关关系不写成因关系；
3. **不扩大外推**：不暗示超出数据支持的普适性；
4. **不改数值**：除非用户明确要求，不更改定量数值；
5. **先读后写 + 每条观点可回溯**：写作前必须先逐篇通读所引文献的 MD 全文（每篇留下阅读记录 / Evidence Record）；正文观点必须来自已读内容并对应到已下载文献（MD 文件）或用户提供的材料，禁止用模型既有知识填充具体发现 / 数字。

## 6. 通用检查清单（交付前自检）

- [ ] 无填充语、机械过渡词、抽象占位语
- [ ] 句式长度有变化，无强行三段式
- [ ] 无 AI 高频词堆砌（中英文）
- [ ] 每条主张的措辞不超过证据强度（因果/首创/普适性/效应量已校准）
- [ ] `first / novel / unprecedented / prove` 类词已加限定或删除
- [ ] 术语冻结列表内词汇未被替换
- [ ] 引用键、公式内容未被改动
- [ ] 所有公式为 LaTeX 语法且 Obsidian 可渲染：行内 `$...$` / 块级 `$$...$$`，无公式截图 / Unicode 伪公式
- [ ] 公式函数算子带反斜杠、符号与术语冻结一致；有编号公式用 `\tag{}` 且正文有对应「式 (N)」
- [ ] 库内论文引用为可点击编号引用（wikilink 显示 `[1]/[2]…`，编号连续无跳号），指向真实存在的 MD（md 阶段逐条核对：每个 `[[…]]` 目标在 `论文/` 下存在对应 `.md` 文件、不是文件夹名；.tex 阶段核对 `\cite` ↔ `.bib` 映射）
- [ ] 含引用的文档文末有 `## 参考文献`（按编号升序，与正文一一对应，无幽灵/漏引）
- [ ] 数字与单位格式统一
- [ ] 无编造文献/数据/他人观点
- [ ] 相关关系未写成因果关系
- [ ] 全文每个段落有控制性观点
