# 工具：科研插图（Scientific Illustration）

> 本工具**不在流程内**，是独立小工具：用户需要科研插图（神经网络结构图、训练/推理架构图、流程图、图形摘要、机理图等）时按需触发。
> **依赖**：scholar 内嵌 `plugins/scientific-illustrator/`（scientific-illustrator v1.5.2 完整嵌入：draw.io 与 PowerPoint/WPS 两个可编辑画图后端 + 审计/修正闭环 + 3 个 MCP server）。MCP 启用方式见下文「MCP 注册（自包含）」。
> **与流程的衔接**：插图为论文素材，按 `03_代码架构设计.md` §4 的图表约定产出（矢量、命名、DPI），供流程三/四引用；图注规范见 `standards/论文写作规范.md` §9。

---

## 触发条件

- 用户要求：画图 / 插图 / 结构图 / 架构图 / 流程图 / 示意图 / 神经网络结构 / graphical abstract / figure / diagram / neural network diagram；
- 或流程三/四需要图表素材时，按需调用本工具（不是流程步骤）。

## 能力与后端选型

| 后端 | MCP 工具前缀 | 适合场景 | 可交付产出 |
|------|--------------|----------|-----------|
| draw.io | `drawio_live_*` | 默认：流程图/结构图/架构图，快速迭代，无 Office 依赖 | `.drawio`（可编辑源）+ SVG/PNG/PDF 导出 |
| PowerPoint / WPS | `powerpoint_*` | 用户要在 PPT 里继续编辑、汇报复用，或希望图直接进演示文稿 | `.pptx`（可编辑源）+ PNG/PDF 导出 |

**选型规则**：
1. 默认 **draw.io**（轻量、矢量、易导出、live 可见绘制）；
2. 用户明确要 PPT/WPS 编辑或汇报 → PowerPoint；
3. 两者产出均为**可编辑对象**（文本/形状/箭头/表格/图表原生可编辑）；**禁止整图截图**充数。

## 使用协议（四角色精简版：设计 → 绘制 → 审计 → 修正）

### 1. 设计（Designer，动手前必做）

- 先写**一句话科学信息**（这张图要传达什么）+ 目标受众与阅读顺序（左→右 / 上→下 / 循环）；
- 定义**布局系统**：画布/幻灯片尺寸、外边距、面板网格、对齐锚点、标准节点尺寸与间距、配色（有限语义色、对比可读）；
- 定义**连接线规则**：正交车道、进出口方向、箭头规范（流程/抑制/反馈/分组用一致约定）、避免交叉（拓扑必需时先改节点布局）；
- 列出全部元素并分类：可编辑文本 / 形状 / 自由线 / 附着边 / 表格图表 / 重复元素 / 不可拆栅格证据。

### 2. 绘制（Drawer，一个区域一个区域）

- 先 `drawio_live_get_capabilities`（或 `powerpoint_get_capabilities`）确认后端能力，再启动/连接并 `status` 确认就绪；
- 已有画布/幻灯片先 `inspect`，**不清空已有内容**（清空需用户明确同意）；
- 按「背景 → 前景」逐区域绘制，对象用稳定 id/名称，适度节奏（`pause_after_ms`）；
- 文本用显式文本框（定宽、换行、对齐），不手动画线——语义关系用**附着边**，坐标轴/刻度/分隔线用**自由线**；
- 精确布局用对齐/分布工具（`drawio_live_align_cells` / `powerpoint_align_shapes` 等），不靠目测；
- 箭头加端点 clearance，避免箭头侵入目标填充/文字。

### 3. 审计（Reviewer，每区域完成后强制）

- 截图/导出渲染证据（`drawio_live_screenshot` / `powerpoint_export_slide_image`）；
- 跑结构审计（`drawio_live_audit_figure` / `powerpoint_audit_figure`），检查八类问题：
  1. 科学语义与文字准确（错字/方向错 = hard failure）；
  2. 可编辑性覆盖（可重建内容不得留在图片里）；
  3. 栅格原子性（一张图片只能含一个不可拆视觉场）；
  4. 几何与对齐（等距、外边距、空白）；
  5. 文字适配（溢出、字体层级、颜色一致）；
  6. 裁剪/重叠/z-order；
  7. 箭头侵入、穿过对象、标签相交、回溯、交叉；
  8. 参考对应（有参考图时）或一致性。

### 4. 修正（Corrector，循环直到通过）

- 审计有 finding → 按**对象级**修正计划执行 → 重新审计 + 新渲染 → 再审计；
- **通过门禁**：语义/可编辑性/裁剪安全 = 1.00，布局与连接线清晰 ≥ 0.95，零 hard failure，无未解释警告；
- 不信任「绘制成功」的自报——以审计与渲染证据为准。

## 关键纪律

- **禁止整图截图**：文字、边框、箭头、图例、表格、坐标轴、普通图表全部用可编辑对象重建；只允许「不可再拆的栅格证据」（如显微镜照片、热图场）作为原子图片插入，且必须声明 `raster_reason`、`source_is_tightly_cropped=true`、`atomic_raster_unit=true`、`contains_reconstructable_content=false`、`decomposition_note`；
- 预测网格、掩码对比、通道堆叠、before/after 等**必须拆成多个原子图片单元**，周围框/网格/图例/箭头用可编辑对象重建；
- 神经网络结构图常用元素：输入/隐藏/输出层块、跳跃连接、loss 分支、注意力模块、数据流箭头——用「形状 + 附着边 + 车道」绘制；
- 训练/推理流程图：正交连接线车道、方向一致（左→右或上→下）、避免交叉与回溯；
- 导出矢量格式（SVG/PDF）用于论文，PNG 仅预览。

## 与 scholar 的衔接

- **产出位置**：`论文/<主题>/figures/`（主题根目录，与 `paper/`、`implementation/` 并列）——**示意图目录**；实验数据图在 `论文/<主题>/implementation/figures/`（流程三产出，03 §4），**两类图不混放**；命名按 03 §4 约定（如 `fig1_architecture.svg` + 可编辑源）；
- **论文写作（流程四）**：`\includegraphics` 引用矢量图；图注与引用规范见 `standards/论文写作规范.md` §9；
- **后端不可用降级**：若 MCP 工具不可用（内嵌 server 未注册且未启用插件），先按「MCP 注册（自包含）」注册；仍不可用才降级用 matplotlib/networkx 等代码生成示意图（明确标注为降级路径，不保证可编辑性）。

## MCP 注册（自包含）

scholar 已完整内嵌 scientific-illustrator 的 3 个 MCP server（`drawio-live` / `drawio-file-utils` / `powerpoint-live`），脚本位于 `plugins/scientific-illustrator/scripts/*.mjs`。

- **Codex 已启用 scientific-illustrator 插件**：直接用其 MCP 工具即可，无需额外注册（与内嵌副本等价）；
- **未启用插件 / 其他 Agent**：把以下 3 条加入本机 Codex `config.toml` 的 `[mcp_servers]`（`<SKILL_DIR>` 替换为 scholar 实际安装目录，如 `C:/Users/<user>/.codex/skills/scholar`），重启 Codex 后生效：

```toml
[mcp_servers.drawio-live]
command = "node"
args = ["<SKILL_DIR>/plugins/scientific-illustrator/scripts/live-server.mjs"]

[mcp_servers.drawio-file-utils]
command = "node"
args = ["<SKILL_DIR>/plugins/scientific-illustrator/scripts/server.mjs"]

[mcp_servers.powerpoint-live]
command = "node"
args = ["<SKILL_DIR>/plugins/scientific-illustrator/scripts/powerpoint-server.mjs"]
```

- **同名 server 只能注册一次**：插件已启用时不要再用内嵌路径注册同名 server（会冲突），二选一；
- 绘图后端需本机可用：draw.io desktop（自动探测或设 `DRAWIO_PATH`）、PowerPoint / WPS（可选）。
